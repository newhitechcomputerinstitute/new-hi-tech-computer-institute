CCC

NIELIT CCC के अनुसार कंप्यूटर, ऑफिस प्रोडक्टिविटी, इंटरनेट और डिजिटल सेवाओं की बुनियादी ट्रेनिंग।

NIELIT FoundationCourse पूछें →

NIELIT CCC Revision 4 (01 अक्टूबर 2023 से लागू) के विषयों पर आधारित तैयारी।

📚 मुख्य विषय / सिलेबस

  • कंप्यूटर परिचय: कंप्यूटर का विकास, उपयोग, हार्डवेयर, सॉफ्टवेयर, CPU, इनपुट/आउटपुट डिवाइस और मेमोरी
  • ऑपरेटिंग सिस्टम: डेस्कटॉप/लैपटॉप और मोबाइल OS, यूजर इंटरफेस, फाइल-फोल्डर और प्रिंटर प्रबंधन
  • Word Processing: दस्तावेज बनाना, खोलना, सेव करना, टेक्स्ट फॉर्मेटिंग, पैराग्राफ, टेबल, पेज सेटअप, प्रिंट और PDF
  • Spreadsheet: सेल, रो-कॉलम, डेटा एंट्री, फॉर्मेटिंग, फॉर्मूले, बेसिक फंक्शन, Sort, Filter और Charts
  • Presentation: स्लाइड बनाना, टेक्स्ट/चित्र/टेबल जोड़ना, थीम, ट्रांजिशन और Slide Show
  • Internet और WWW: ब्राउज़र, वेबसाइट, सर्च इंजन, नेटवर्क की मूल जानकारी और ऑनलाइन सेवाएँ
  • E-mail, Social Networking, e-Commerce और e-Governance सेवाएँ
  • Digital Financial Tools: UPI, इंटरनेट बैंकिंग, डिजिटल भुगतान और संबंधित सावधानियाँ
  • Future Skills और Cyber Security का परिचय

🧑‍💻 प्रैक्टिकल में उपयोग होने वाले ऑफिस टूल

  • LibreOffice Writer: CCC के Word Processing भाग का अभ्यास
  • LibreOffice Calc: CCC के Spreadsheet भाग का अभ्यास
  • LibreOffice Impress: CCC के Presentation भाग का अभ्यास

ये LibreOffice ऐप संस्थान में प्रैक्टिकल कराने के लिए चुने गए टूल हैं। NIELIT के CCC सिलेबस में इन भागों को Word Processing, Spreadsheet और Presentation के रूप में बताया गया है; सिलेबस किसी एक ब्रांड के सॉफ्टवेयर तक सीमित नहीं है।

🎯 किनके लिए उपयोगी?

शुरुआती विद्यार्थी और वे लोग जो कंप्यूटर व डिजिटल सेवाओं का बुनियादी उपयोग सीखना चाहते हैं।

आधिकारिक पाठ्यक्रम: NIELIT CCC Revision 4. संस्थान में कराए जाने वाले अतिरिक्त अभ्यास बैच के अनुसार अलग हो सकते हैं।

NIELIT O Level

चार अनिवार्य पेपर: IT Tools & Network Basics, Web Designing, Python और IoT।

NIELIT · Revision 5.1Course पूछें →

NIELIT ‘O’ Level (IT) — Revision 5.1 के चार अनिवार्य थ्योरी मॉड्यूल। इनके साथ संबंधित प्रैक्टिकल परीक्षाएँ और प्रोजेक्ट भी पाठ्यक्रम का हिस्सा हैं।

📘 Paper 1 — M1-R5.1: Information Technology Tools and Network Basics

  • कंप्यूटर और नवीन IT गैजेट्स, कंप्यूटर का विकास और उपयोग
  • हार्डवेयर, सॉफ्टवेयर, CPU, इनपुट/आउटपुट डिवाइस, मेमोरी और स्टोरेज
  • Desktop, Laptop और Mobile Operating System; फाइल-फोल्डर और प्रिंटर प्रबंधन
  • Word Processing: दस्तावेज, फॉर्मेटिंग, टेबल, Mail Merge, PDF और प्रिंटिंग
  • Spreadsheet: सेल, फॉर्मूले, फंक्शन, Sort/Filter, Advanced Filter, What-if Analysis, Pivot Table, Charts और Data Validation
  • Presentation: स्लाइड, टेम्पलेट, Master Slide, ऑब्जेक्ट, ट्रांजिशन, Slide Show और प्रिंटिंग
  • Computer Networks, LAN/WAN, Topology, Internet, WWW, URL, IP Address और ब्राउज़र
  • E-mail, Social Networking, e-Governance, Digital Financial Tools, Future Skills और Cyber Security

🌐 Paper 2 — M2-R5.1: Web Designing and Publishing

  • Web Design का परिचय: Website, Webpage, Front-end/Back-end, Client/Server और Responsive Design
  • Code Editors का उपयोग और फाइल बनाना/सेव करना
  • HTML और HTML5: Basic Structure, Text Formatting, Links, Images, Tables, Lists, Forms और Multimedia
  • CSS: Selectors, Background, Box, Border, Positioning, Lists, Tables, Menus और Image Gallery
  • CSS Framework — NIELIT सिलेबस में W3.CSS
  • JavaScript: Variables, Operators, Conditions, Events और Form Validation
  • AngularJS का परिचय: Expressions, Modules और Directives
  • Photo Editing के मूल टूल, Layers, Filters और Web Publishing/Hosting की बुनियाद

🐍 Paper 3 — M3-R5.1: Programming and Problem Solving through Python

  • Programming की मूल अवधारणाएँ, Algorithms और Flowcharts
  • Python Interpreter, Program Structure, Comments, Literals, Constants और Built-in Data Types
  • Numbers, Strings, Input/Output, Indexing और Slicing
  • Operators, Expressions, if/else और अन्य Conditional Statements
  • Loops: for, while, break, continue और pass
  • Sequence Data Types: List, Tuple और Dictionary
  • Built-in और User-defined Functions, Parameters, Return और Recursion
  • File Processing: फाइल खोलना, पढ़ना, लिखना और बंद करना
  • Modules, Scope और NumPy की मूल बातें

📡 Paper 4 — M4-R5.1: Internet of Things and its Applications

  • IoT का परिचय, उपयोग, Devices, Architecture, Building Blocks और Communication Models
  • Things and Connections: Feedback Loop, TCP/IP और OSI Model, Wired/Wireless Connectivity
  • Sensors, Actuators, Transducers और Microcontrollers
  • Arduino Platform और Arduino IDE का परिचय
  • Embedded C की बुनियाद: Variables, Data Types, Operators, Conditions, Loops, Arrays और Functions
  • Arduino के Digital/Analog Pins और Sensors/Actuators को जोड़ने का अभ्यास
  • IoT Applications, Device Security और IoT Ecosystem
  • सिलेबस में शामिल Soft Skills और Personality Development

🧪 प्रैक्टिकल और प्रोजेक्ट

  • M1 से M4 तक के विषयों पर आधारित चार Practical मॉड्यूल/परीक्षाएँ
  • प्रोजेक्ट: सीखी गई IT स्किल्स का उपयोग करके मौलिक, वास्तविक उपयोग वाला प्रोजेक्ट तैयार करना

सिलेबस स्रोत: NIELIT O Level (IT), Revision 5.1, जुलाई 2022. आधिकारिक संरचना में चार compulsory theory modules, practicals और project शामिल हैं। यह संस्थान की प्रशिक्षण जानकारी है; NIELIT पंजीकरण/परीक्षा संबंधी नियम अलग से लागू होते हैं।
